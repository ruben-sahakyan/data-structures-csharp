# Data Structures in C#

This repository contains manual implementations of classic data structures in C#, 
with a focus on clean code, time/space complexity analysis, and unit testing.

-----------------
## Purpose

The goal of this project is to deepen understanding of core data structures 
by implementing them from scratch, documenting their behavior, 
and validating them with unit tests.
